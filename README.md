# Diflet

Jogo de cartas bíblico (Fé, Força, Caráter e Milagre). Jogue em **https://filipeidea.github.io/diflet**.

- Login com conta Google (Firebase Authentication).
- Coleção, dracmas, pacotes e partidas salvos no Firestore, presos à conta de cada jogador.
- `firestore.rules`: regras de segurança do banco (cada jogador só mexe nos próprios dados; o dono lê tudo para o painel de testes).

O `index.html` é gerado a partir da versão de teste do jogo; não edite à mão.
